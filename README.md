# Feedback Paths

Project page for *Feedback Paths*, a Stanford master's research project by Rachel Zhao on how English learners engage with peer and AI feedback, and how that feedback becomes revision.

A single static page (`index.html`), with no build step. On Vercel, import this repository with the framework preset set to "Other".

## Contents

- `index.html`: the project page.
- `studio/index.html`: **Feedback Paths Studio**, a working prototype. Students discuss peer and AI feedback, every reply is coded for engagement, an explicit scaffolding policy picks the AI's next move and fades support, revisions are aligned to feedback, and a teacher dashboard shows feedback journeys. On the web it runs a rule-based coach; the classroom version on claude.ai uses Claude and saves submissions.
- `prototype/index.html`: source of the claude.ai classroom version.
